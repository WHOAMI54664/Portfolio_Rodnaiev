# Danylo Rodnaiev — Portfolio

Multilingual portfolio built with Next.js, TypeScript, React and JavaScript-powered interactions.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

The repository is ready to import into Vercel. The site does not require environment variables.
